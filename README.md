# Letter Rip

How many words can you rip out of one big word?

## Modes

- **Daily Rip**: the same word for everyone each day (Irish time), 2 minutes, one go per day, with a streak counter and a share button.
- **Quick Rip**: a random 7–9 letter word, 2 minutes. Play as often as you like.
- **Kids' Rip**: an easier 6–7 letter word and 3 minutes.
- **Challenge** (2+ players, three strikes): coming next.

Scores and streaks are saved in the browser on each device. No sign-in, and no Firebase needed yet.

## Putting it online (GitHub + Vercel)

1. Unzip `letter-rip.zip` on your computer.
2. On GitHub, create a new empty repository called `letter-rip` (no README).
3. Open a terminal in the unzipped `letter-rip` folder and run:
   ```
   git remote add origin https://github.com/u01dkr/letter-rip.git
   git push -u origin main
   ```
4. In Vercel, click **Add New → Project**, pick `letter-rip`, and click **Deploy**. No settings or environment variables needed.

## Running it on your computer

```
npm install
npm run dev
```
Then open http://localhost:3000.

## How it works

- `public/dict.txt`: about 51,000 accepted words (common words marked with `*`). Rude words are filtered out.
- `src/data/roots.json`: about 2,450 normal and 550 easy root words, each chosen so there are plenty of words to find.
- Both are generated by `npm run words` (`scripts/build-words.mjs`) from the SCOWL word lists. Edit the allow/block lists at the top of that script and re-run it to change what's accepted.
- `src/lib/words.ts`: the shared rules (can this word be made, scoring, daily word). Challenge mode will reuse these.
- Scoring: 3 letters = 1, 4 = 2, 5 = 3, 6 = 5, 7 = 8, 8 = 12, 9 = 16. Using every letter (a **Full Rip**) adds +10.
