# Letter Rip

Two word games in one app:

- **Letter Rip**: how many words can you rip out of one big word?
- **Word Ladder**: change one letter at a time (LOVE → MOVE → MODE → MADE…). How high can you climb?

The switch at the top of the home page picks the game.

## Letter Rip modes

- **Daily Rip**: the same word for everyone each day (Irish time), 2 minutes, one go per day, with a streak counter and a share button.
- **Quick Rip**: a random 7–9 letter word, 2 minutes. Play as often as you like.
- **Kids' Rip**: an easier 6–7 letter word and 3 minutes.
- **Challenge**: 2–8 players, each on their own phone. Take turns making words from the same big word, no repeats. Run out of time and you get a strike; three strikes and you're out. The clock shrinks as the word gets used up (20s, then 15s, then 10s; Kids is 30/25/20). A **Full Rip** wipes off a strike. Last one standing has the Last Word!

## Word Ladder modes

- **Daily Ladder**: the same start word for everyone each day, one go.
- **Quick Ladder**: a random everyday four-letter word, 15 seconds per move.
- **Kids' Ladder**: easier start words, 25 seconds per move.
- Your score is the number of rungs. The run ends when the clock runs out or you hit a **dead end** (a word with no unused moves left).
- **Challenge**: pick Word Ladder in the lobby. Take turns changing one letter, 15 seconds a turn (25 for Kids). Leave the next player a dead end and they get a strike straight away.

Solo scores and streaks are saved in the browser on each device. Challenge games use Firebase.

## Putting it online (GitHub + Vercel)

1. Unzip `letter-rip.zip` on your computer.
2. On GitHub, create a new empty repository called `letter-rip` (no README).
3. Open a terminal in the unzipped `letter-rip` folder and run:
   ```
   git remote add origin https://github.com/u01dkr/letter-rip.git
   git push -u origin main
   ```
4. In Vercel, click **Add New → Project**, pick `letter-rip`, and click **Deploy**.

## Turning on Challenge mode (Firebase)

Letter Rip shares Acro Party's Firebase project. Its games are kept in their own `letterRip` collection, so the two never mix.

1. **Firestore rules:** In the Firebase console, open the Acro Party project → **Firestore Database → Rules**. Replace everything with the contents of `firestore.rules` from this repo (it keeps Acro Party's rule and adds one for Letter Rip) → **Publish**.
2. **Vercel settings:** In Vercel, open the **acro-party** project → **Settings → Environment Variables** and copy these four values. Then open the **letter-rip** project → **Settings → Environment Variables** and add them with the same names:
   - `NEXT_PUBLIC_FIREBASE_API_KEY`
   - `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`
   - `NEXT_PUBLIC_FIREBASE_PROJECT_ID`
   - `NEXT_PUBLIC_FIREBASE_APP_ID`
3. In the letter-rip project, go to **Deployments → ⋯ → Redeploy** so the new settings take effect.

Until then, the Challenge card on the home page says it needs setting up, and the solo games work as normal.

## Running it on your computer

```
npm install
npm run dev
```
Then open http://localhost:3000.

## How it works

- `public/dict.txt`: about 51,000 accepted words (common words marked with `*`). Rude words are filtered out.
- `src/data/roots.json`: about 2,450 normal and 550 easy root words, each chosen so there are plenty of words to find, plus about 390 normal and 90 easy Word Ladder start words with plenty of moves.
- Both are generated by `npm run words` (`scripts/build-words.mjs`) from the SCOWL word lists. Edit the allow/block lists at the top of that script and re-run it to change what's accepted.
- `src/lib/ladder.ts`: Word Ladder rules (one-letter changes, dead ends, start words).
- `src/lib/words.ts`: the shared word rules (can this word be made, scoring, daily word).
- `src/lib/challenge.ts`: challenge settings (turn times, strikes, players) at the top; `src/lib/challengeActions.ts` changes the game in the database.
- `testing/fake-firebase/`: a pretend database for testing challenge games across browser tabs without Firebase (`FAKE_FIREBASE=1`). Not used on the live site.
- Scoring: 3 letters = 1, 4 = 2, 5 = 3, 6 = 5, 7 = 8, 8 = 12, 9 = 16. Finding a different word that uses every letter (a **Full Rip**, e.g. PAINTERS → PERTAINS) adds +10. The given word itself doesn't count.
